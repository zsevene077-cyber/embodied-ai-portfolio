# DM05 训练后回归与覆盖审计 / Training Regression

[项目索引](../README.md) · [个人主页](https://zsevene077-cyber.github.io) · [编辑方法](../CONTRIBUTING.md)

领域：训练与推理、回归验证。记录年份：2026。

## 问题与参与 / Context and Contribution

训练任务结束后，需要继续核对是否执行了有效训练步数、权重是否变化、推理能否使用，以及 checkpoint 是否被完整评测。

我参与 LoRA / Full SFT 训推回归与 checkpoint 评测，跟进显存、通信及任务结束但实际训练步数为零等问题。下面的量化结果只对应一个 LoRA checkpoint 的四套 LIBERO 评测与覆盖审计，不把不同训练检查合并成一项训练收益。

## 评测条件 / Evaluation Conditions

| 条件 | 本次记录 |
| --- | --- |
| 模型 | DM05 LoRA checkpoint 30k |
| 任务套件 | LIBERO Spatial、Object、Goal、LIBERO-10 |
| 计划范围 | 每套 500 episodes，共 2,000 episodes |
| 完成判定 | 恢复执行后，对最终结果检查唯一 episode、覆盖与系统错误 |

当前公开摘要没有给出完整训练配方、权重版本、评测软件版本和种子清单，数值应理解为该次记录的结果，不能作为可独立复现的完整实验协议。

## 结果 / Results

| 套件 | 唯一 episode / 计划 | 成功次数 | 该次运行成功率 |
| --- | --- | --- | --- |
| LIBERO Spatial | 500 / 500 | 490 | 98.0% |
| LIBERO Object | 500 / 500 | 497 | 99.4% |
| LIBERO Goal | 500 / 500 | 485 | 97.0% |
| LIBERO-10 | 500 / 500 | 461 | 92.2% |
| 合计 | 2,000 / 2,000 | 1,933 | 96.65% |

67 个 episode 的策略结果为失败，未知结果为零。这些任务失败与运行系统错误分开统计。

| 最终审计项 | 记录结果 |
| --- | --- |
| 缺失、重复、越界 | 均为 0 |
| worker 分配违规 | 0 |
| 已扫描 worker 日志中的系统错误匹配 | 0 |
| 已记录 worker 退出状态 | 74 个，均为 0 |

系统错误项是本次审计规则与扫描范围下的结果，不表示任何可能的系统问题都被排除。审计确认的是最终唯一覆盖，恢复执行本身仍属于实验过程的一部分。

## 证据与边界 / Evidence and Limits

- 96.65% 属于这个 checkpoint 与相应评测协议，不是对所有环境的泛化保证。
- 历史基座结果并非同条件受控 A/B，不能据此声称 LoRA 微调带来了提分。
- 覆盖完整说明“评测是否测全”，模型效果与训练收益还需要匹配条件的对照。
- 本人的工作是参与训推回归、评测执行和审计，不将团队模型或该次成功率写成个人算法创新。
- 原始权重、预测结果和日志不随本公开仓库提供。

## 认识与下一步 / Reflection and Next Steps

训练、推理与评测需要连续的证据：有效训练步数和权重变化支持训练过程判断，可用推理支持服务判断，完整覆盖支持评测完成判断。

后续想法是在相同代码、数据、种子和执行配置下做基座与微调模型对照，并分别记录模型失败、系统错误和资源消耗。完成这种对照前，保留当前结果的有限结论。
